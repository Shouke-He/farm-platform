三、分模块接线

3.1 电源与下载（第一条线先接这个）

线缆接法
白色 Type-C 数据线USB-A 端 → 电脑 USB 口（或手机充电头），Type-C 端 → ESP32
  • 插上后 ESP32 板上电源指示灯（红色）亮即供电正常。
  • 插电脑 USB 口可直接下载程序 + 供电；用手机充电头只有供电（下载程序时插回电脑）。

3.2 DHT11 温湿度模块（带 16cm 三芯线）

模块是 3 孔排母，卖家已插好三根端子线，线色非常规：橙=VCC、黄=DATA、绿=GND（不是红黑黄！），另一端是黑色 3P 连体母头。

DHT11 丝印（模块上 VCC/DATA/GND）线色→ ESP32
VCC（+）橙色3V3
DATA（S）黄色D4
GND（-）绿色GND
  • 黑色 3P 连体母头同样需要拆壳成单根（针从背面小方孔压弹片抽出）或跳线转接
  • 模块已集成上拉电阻；通电后模块上指示灯亮即供电正常
  • 放置：放在花盆旁、避开阳光直射和浇水喷溅处，测量环境温湿度

3.3 电容式土壤湿度传感器（实物 HW-390，板印 GND/UCC/AUOT 有错字）

板上是白色 3 孔母座，卖家已插好三根端子线，线色非常规：黄=GND、红=VCC、黑=AOUT（黑线是信号不是地！），另一端是黑色 3P 连体母头。接线以板面丝印为准，别信线色习惯：

板面丝印（左→右）含义线色→ ESP32
GND地黄色GND
UCC（错字=VCC）电源正红色3V3
AUOT（错字=AOUT）模拟输出黑色D32
  • 黑色 3P 连体母头拆壳成单根后按上表接
  • 插入土壤时不要超过 PCB 上的警戒线（电路板部分不能埋土里，防止腐蚀短路）
  • 读数规律（固件里按此校准）：空气中约 0%～15%，水中约 85%～100%，正常盆土约 40%～70%
  • 如果转接线不够长，用 2 根母对母杜邦线串联延长即可

3.4 4 针光敏电阻模块（无带线，4 根裸排针）

模块 4 个排针，丝印从左到右：AO DO GND VCC（模块倒放时字是反的，翻正再认）：

光敏模块→ ESP32说明
VCC（最右）3V33.3~5V
AO（最左）D33模拟输出，光照越强电压越高
GND（左 3）GND
DO（左 2）不接数字阈值输出，本项目用 AO
  • 模块上电位器调节的是 DO 翻转阈值，本项目不用 DO，电位器不用调
  • 通电后 PWR 灯亮即正常
  • 放置：感光头朝上，放在能代表花盆受光的位置（窗台）

3.6 电源：3V3 只有一个引脚，3 根 VCC 线并插

本板 3V3 只有 1 个（下排第 1 个），GND 有 2 个（下排第 2、上排第 2）。三个传感器的电源线（DHT11 橙线、土壤红线、光敏 VCC）全部并插到同一个 3V3 引脚：

  1. 第一根先插到底
  2. 第二根从侧面斜 45° 套上针尖，再压到底
  3. 第三根套前用镊子把母头弹片向内夹紧一点再插
  4. 插完轻拽每根，不掉即接触 OK（总电流约 10mA，供电无压力）
⚠️ 不要把任何传感器接 VIN（上排第 1，5V）：DHT11 数据线上拉到 5V 会超 ESP32 引脚极限；光敏/土壤的 AO 输出超 3.3V 会损伤 ADC。全部必须 3V3。

四、上电前检查清单（必做）

  • [ ] Type-C 线已插 ESP32，红色电源灯亮
  • [ ] 杜邦线没有插反/插错：3V3 不会接错到 5V（核对每根线的两端）
  • [ ] 三个模块 GND 都与 ESP32 GND 相连（共地）
  • [ ] 光敏 DO 没接线（只用 AO）
  • [ ] HY-190 只插了探头入土，PCB 与警戒线在土面上
  • [ ] DHT11 指示灯亮、光敏 PWR 灯亮、HY-190 无发热

六、接完线后的验证步骤

  1. 烧录测试：Arduino IDE 选板 ESP32 Dev Module，依次读取两路 ADC（D32/D33）和 DHT11（D4），串口监视器打印。
  2. 预期读数：
  3. 土壤（D32）：空气≈0~15%，插水≈90~100%，插盆土≈40~70%
  4. 光敏（D33）：手掌遮挡明显下降，手电照明显上升
  5. DHT11：室温附近（±2°C 误差正常），湿度 30~70%
  6. 测试通过后，烧录正式固件（WiFi + MQTT 发布 farm/device/SN-xxx/telemetry，JSON 与模拟器一致：{"t":..,"soil_humidity":..,"temp":..,"humi":..,"lux":..}），校准规则：空气 0%、水 100% 线性映射。
